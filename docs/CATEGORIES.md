# 分类体系

只有 5 个分类，不要新增。归类拿不准时按下面第一条命中的规则走。

| 分类 | 目录 | 出一张什么图 |
| --- | --- | --- |
| **游戏素材** | `prompts/game-assets/` | 皮肤包、道具图标、特效贴图、特效帧 |
| **角色人像** | `prompts/character/` | 人物立绘、头像、NPC、真人风肖像 |
| **场景背景** | `prompts/scene/` | 关卡背景、横幅、氛围图、地图 |
| **UI 控件** | `prompts/ui/` | 按钮、弹窗底框、进度条、图标 |
| **风格化** | `prompts/style/` | 风格迁移、重绘、扩图、二次编辑 |

---

## 归类判断顺序

**第 1 问：是不是在改动已有图？**

是 → `style/`（无论改的是什么内容，只要输入是图不是文字）

**第 2 问：产出是单个可交互控件吗？**

是 → `ui/`（按钮、开关、弹窗框、进度条这类要拼进界面的零件）

**第 3 问：主体是单个道具/物件吗？**

是 → `game-assets/`（图标、道具、特效贴图）

**第 4 问：画面里有人物吗？**

是 → `character/`

**第 5 问：以上都不是** → `scene/`

---

## 容易混的几组

| 容易混 | 归哪 | 为什么 |
| --- | --- | --- |
| 皮肤包的**按钮**图 vs UI 按钮模板 | 看归属：属于某个皮肤包成套产出 → `game-assets`；通用控件 → `ui` |
| 游戏**道具图标** vs UI **功能图标** | 有世界观/美术设定 → `game-assets`；纯功能性（设置/关闭）→ `ui` |
| 带人物的**场景图** | `character/` | 人物是主体时以人物为准；只有当人物是远景点缀才归 `scene/` |
| 把线稿**上色** | `style/` | 输入是图，走风格化 |
| 给已有角色**换装** | `style/` | 同上，保留了原图结构 |

## tag 速查（常用）

写模板时从这里挑，避免同义词泛滥：

**产出形态**：`成套` `单图` `精灵图` `无缝贴图` `透明底`
**画风**：`写实` `二次元` `像素` `低多边形` `手绘` `3D渲染`
**用途**：`皮肤包` `图标` `道具` `特效` `背景` `头像` `UI`
**技术**：`图生图` `重绘` `扩图` `抠图` `超分` `风格迁移`
**约束**：`居中` `纯色底` `可平铺` `无文字`
