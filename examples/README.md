# 案例

存放**完整出图案例** —— 不只是一段 prompt，而是「用什么 prompt + 什么参数 +
出了什么结果 + 哪里翻车 + 怎么改」的完整记录。

案例的价值在于**记录失败**。一个只写成功结果的案例没有参考意义。

---

## 案例格式

一个案例一个 `.md`，文件名 `<日期>-<主题>.md`，例：`2026-10-01-敦煌皮肤包.md`。

```markdown
# <案例标题>

- 日期：2026-10-01
- 使用的模板：`prompts/game-assets/game-skin-pack-set.md`
- 出图工具：ImageGen / Midjourney / 即梦
- 最终变量取值：
  - THEME = 敦煌壁画
  - STYLE_REF = Chinese Dunhuang murals

## 目标

这次要出什么图、给谁用、验收标准是什么。

## 第一轮

prompt（原样贴）+ 参数 + 结果问题。

## 迭代记录

| 轮次 | 改了什么 | 结果 |
| --- | --- | --- |
| 1 |  |  |
| 2 |  |  |

## 结论

- 哪些写法有效，为什么
- 哪些无效，别再试
- **是否需要回头修改模板** —— 如果踩的坑是通用的，去改对应的 prompt 模板

## 配图

> 示意图放同目录下，单图 ≤ 500KB，命名 `<案例名>-N.png`。
> 不要提交批量产物和中间图。
```

---

## 注意

- 案例里如果发现了模板本身的通用问题，**要回头改模板**，而不是只写在这里
- 出图产物（大批量原图）不进仓库，只放少量压缩过的示意图
